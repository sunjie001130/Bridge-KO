## Reuse vs re-run
- **Reused (no DNN re-run):** Fig 4 AUC panels + sdp/asdp/equi AUCs are cached in
  `results/cached_auc_from_pdf.csv` (transcribed from `../LMM_microbiomap.pdf`, verified
  against `../code/aim3_AUC_boxplots.Rmd`). PCA = main figure; UMAP = supplementary.
- **New runs:** everything else (baselines, ablations, within-fold ComBat, bootstrap,
  permutation, covariate models).

## Pipeline order
1. **Phase 0** — `scripts/install_r_pkgs.R` (once); env verified.
2. **Data prep** — `Rscript scripts/prep_pca_knockoffs.R` → best-config + 4 proximity
   groups train/test knockoff CSVs in `results/pca_knockoffs/`.
3. **Phase A** — `Rscript scripts/knockoff_covariance.R` (covariance + runtime);
   re-plot cached AUCs; UpSet (needs per-method selections).
4. **Phase B** — `python scripts/baselines.py` (target-only, DANN, CORAL).
5. **Phase C** — `Rscript scripts/combat_source_only.R`, `scripts/prep_ablations.R`
   (random subset) → `run_bridgeko.py` per group.
6. **Phase D** — `scripts/combat_within_fold.R` → `run_bridgeko.py` (sensitivity).
7. **Phase E** — `python scripts/stability_auc.py --mode bootstrap|permutation`;
   `Rscript scripts/fig4e_recolor.R`.
8. **Phase F** — `Rscript scripts/genera_stability_stats.R`; permutation of selections.
9. **Phase G** — `Rscript scripts/build_covariates.R`,
   `python scripts/covariate_prediction.py`, `Rscript scripts/combat_covariate_aware.R`.
10. **Figures** — `Rscript scripts/make_figures.R` (incremental; skips missing inputs).

DNN jobs scale out via `sbatch/run_bridgeko.sbatch` (SLURM array over groups).
Results → `results/`; figures → `figures/`; logs → `logs/`.

## Reproducing the revision

### What is in this repository
- `scripts/` — all analysis code (Python DNN engine + R prep/stats/plots).
- `sbatch/`, `run_all.sh` — SLURM submission scripts and the top-level run order.
- `figures/` — every revision figure (PDF).
- `results/` — **summary tables only** (per-arm AUCs, knockoff covariance/runtime,
  genera selection-frequency & enrichment, stability bootstrap/permutation, the
  covariate logistic-test coefficients/LRT). The large intermediate matrices
  (per-seed knockoff designs, full source/target matrices, raw bootstrap draws) are
  **not** tracked — they are regenerated by the scripts above.
- `Bac_final_model/` — the 10 per-run knockoff-selected genera lists (R1#9).

### Data availability (not redistributed here)
- **Source microbiome data** (Microbiomap source + the 5-cohort clinical target) derive
  from McCulloch, Davar, Rodrigues *et al.*, *Nat Med* **28**, 545–556 (2022),
  https://doi.org/10.1038/s41591-022-01698-2. The cohort sequencing/analytic details used
  for the sequencing-method covariate come from that paper's **Supplementary Table 3**.
  Obtain these files from the publisher; they are not re-hosted here for copyright reasons.
- **Large matrices** (`big_scaled*.csv` ~350 MB, `microbiomap_expr.csv`, etc.) exceed
  GitHub limits. Host them on Zenodo/figshare and point `run_all.sh` at the download, or
  regenerate from the source data with the prep scripts.
- **Per-sample clinical covariates** (`results/covariates_154.csv`) are *not* committed;
  regenerate them from the cited supplement with `scripts/build_covariates.R`. The
  sequencing-method covariate is the verified 3-level shotgun profiler family
  (JAMS / MetaOMineR / MetaPhlAn), which is 1:1 with cohort/site.

### Paths
Scripts use absolute cluster paths (`/home/sunj107/scratch/...`) and a vendored `DL`
package at `../code/DL`. Adjust the `WD`/path constants at the top of each script to your
environment before running.
